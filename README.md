## Methodology
- **Regression Analysis:** Multiple linear regression is used to understand the impact of different GPU characteristics on memory speed.
- **Random Forest Regression:** Used for comparison to analyze non-linear relationships.
- **Statistical Visualization:** Box plots, histograms, and correlation matrices help identify patterns and relationships.
- **Data Cleaning & Processing:** Missing values, categorical encoding, and feature scaling are applied to improve model performance.

## Key Findings
- Certain GPU characteristics significantly influence memory speed.
- Linear regression provides interpretability, while Random Forest regression offers better predictive performance.
- Data preprocessing and feature selection play crucial roles in improving model accuracy.
